# 🔌 결선도 에디터

## 소개

Jetson Orin Nano의 GPIO 배선처럼, 12V 버튼·릴레이·SMPS·컨트롤러 보드가 얽힌 결선도를 문서화할 때 쓰려고 만든 도구입니다. 화면은 PCB(초록 기판), 부품 박스(버튼/릴레이/SMPS 등), 포트/핀 마커, 배선(꺾인 선), 텍스트, 범례 박스로 구성되며, 전부 마우스 드래그와 단축키로 배치·편집합니다.

## 주요 기능

- 🟩 **PCB** — 초록 기판. 드래그로 자유로운 크기 지정, 이름·글자 크기 조절
- 🟦 **부품 박스** — 버튼·릴레이·SMPS 등 범용 박스. 색상 테마 6종, 이름·글자 크기 조절
- 🔌 **포트/핀 마커** — 원(●) 또는 사각형(■)으로 커넥터 핀 표시, 색상 6종
- 〰️ **배선** — 클릭으로 여러 번 꺾을 수 있는 선. `Shift`로 직각 스냅, 색상 6종, 굵기 조절, 점 추가/삭제
- 🏷️ **텍스트 라벨**
- 📋 **배선 범례 박스** — "이 색 선은 LAN선이다" 같은 설명을 표로 정리
- ▣ **그룹 & 컴포넌트 라이브러리** — 여러 요소를 묶어 이름 붙이고, 저장해뒀다가 다음에 한 번에 다시 불러오기
- 🔼🔽 **겹침 순서 조절** — 맨 앞으로/맨 뒤로 등, 요소가 겹칠 때 위아래 순서 변경
- 📐 **격자 스냅, 확대/축소, 화면 이동, 전체보기**
- ↩️ **실행취소/다시실행**, 복제, 복사/붙여넣기
- 🖱️ **드래그로 다중 선택**(마퀴 선택), `Shift`+클릭으로 선택 추가/제거
- 💾 **자동 저장**(브라우저), PNG · SVG · JSON 내보내기, JSON 불러오기
- 📴 인터넷 연결 없이도 완전히 동작 (단일 HTML 파일)

## 화면 구성

| 위치 | 내용 |
|---|---|
| 상단 바 | 실행취소/다시실행, 확대/축소, 격자 스냅, 라이브러리 열기, 내보내기/가져오기, 전체지우기, 단축키 안내 |
| 왼쪽 툴바 | 도구 선택(선택/PCB/박스/배선/텍스트/포트/범례), 다음에 그릴 색상, 포트 기본 모양 |
| 왼쪽 서랍(📦) | 저장해둔 컴포넌트 라이브러리 (그룹으로 묶어 저장한 블럭들) |
| 가운데 캔버스 | 실제로 그림을 그리는 영역 |
| 오른쪽 패널 | 선택한 요소의 이름·색상·크기 등 속성, 다중 선택 시 그룹 묶기 |
| 하단 상태바 | 현재 도구, 좌표, 요소 개수, 저장 상태 |

## 단축키 전체 목록

### 도구 전환

| 키 | 동작 |
|---|---|
| `V` | 선택 / 이동 |
| `P` | PCB 배치 (드래그로 크기 지정, 클릭만 하면 기본 크기) |
| `B` | 부품 박스 배치 |
| `W` | 배선 그리기 |
| `T` | 텍스트 라벨 |
| `O` | 포트/핀 배치 |
| `L` | 배선 범례 박스 배치 |

### 배선 그리는 중

| 키 | 동작 |
|---|---|
| 클릭 | 꺾인점 추가 |
| `Shift` (누른 채 이동) | 직각(가로/세로)으로 스냅 |
| 더블클릭 / `Enter` | 배선 완료 |
| `Esc` | 그리던 배선 취소 |

### 선택 / 편집

| 키 | 동작 |
|---|---|
| 빈 캔버스 드래그 | 마퀴(사각형) 다중 선택 |
| `Shift` + 드래그(빈 캔버스) | 기존 선택에 추가 |
| `Shift` + 클릭(요소) | 선택 토글 |
| 더블클릭 (도형) | 이름 편집 |
| 더블클릭 (배선 위) | 꺾인점 추가 |
| 더블클릭 (꺾인점 위) | 꺾인점 삭제 |
| `Delete` / `Backspace` | 선택 삭제 |
| 방향키 | 선택 요소 1px 이동 |
| `Shift` + 방향키 | 격자 단위로 이동 |
| `1` ~ `6` | 배선/포트 색상 선택 |

### 편집 동작

| 키 | 동작 |
|---|---|
| `Ctrl` + `Z` | 실행취소 |
| `Ctrl` + `Shift` + `Z` (또는 `Ctrl+Y`) | 다시실행 |
| `Ctrl` + `D` | 복제 |
| `Ctrl` + `C` / `Ctrl` + `V` | 복사 / 붙여넣기 (여러 번 붙여넣으면 조금씩 밀려서 배치) |
| `Ctrl` + `G` | 선택한 요소들을 그룹으로 묶기 |
| `Ctrl` + `]` / `Ctrl` + `Shift` + `]` | 한 단계 앞으로 / 맨 앞으로 |
| `Ctrl` + `[` / `Ctrl` + `Shift` + `[` | 한 단계 뒤로 / 맨 뒤로 |

### 화면 / 기타

| 키 | 동작 |
|---|---|
| 마우스 휠 | 확대 / 축소 |
| 스페이스 + 드래그 (또는 휠 클릭 드래그) | 화면 이동(패닝) |
| `0` | 전체 내용이 보이도록 맞추기 |
| `+` / `-` | 확대 / 축소 |
| `G` | 격자 스냅 켜기/끄기 |
| `Esc` | 취소 / 선택 해제 |
| `?` | 단축키 안내 열기/닫기 |

## 기본 사용 흐름

1. `P` 또는 `B`를 누르고 캔버스를 드래그해 PCB·부품 박스를 놓습니다. 놓자마자 이름을 입력할 수 있는 창이 바로 열립니다.
2. `W`를 눌러 배선을 그립니다. 클릭할 때마다 꺾이고, `Shift`를 누르면 직각으로 꺾입니다. 더블클릭이나 `Enter`로 완료합니다.
3. `O`로 포트를 찍어 핀 이름(예: `3.3V`, `GND`, `GPIO29`)을 붙입니다.
4. `L`로 범례 박스를 놓고, 오른쪽 패널에서 색상별 배선 의미를 적어둡니다.
5. 다 그렸으면 상단의 PNG/SVG로 내보내 문서에 붙여넣거나, JSON으로 저장해 나중에 다시 불러옵니다.

## 그룹 & 라이브러리로 재사용하기

Jetson 포트 구성처럼 자주 반복해서 그리는 블럭은 매번 새로 그릴 필요 없이 저장해뒀다가 이름으로 바로 불러올 수 있습니다.

1. 캔버스를 드래그해 여러 요소를 한 번에 선택합니다 (마퀴 선택).
2. `Ctrl+G`로 그룹으로 묶고, 이름을 입력합니다 (예: `Jetson`).
3. 오른쪽 패널의 **📦 라이브러리에 저장**을 누릅니다.
4. 다음에 필요할 때 상단 **📦 라이브러리** 서랍을 열고 **가져오기**를 누르면 화면 중앙에 그대로 다시 놓입니다.

라이브러리는 브라우저에 별도로 저장되기 때문에 **전체지우기**를 해도 남아 있습니다.

## 저장 / 내보내기 / 가져오기

- 작업 내용은 브라우저에 **자동 저장**됩니다 (같은 브라우저·같은 주소로 다시 들어오면 이어서 작업 가능).
- 상단의 **PNG / SVG / JSON** 버튼으로 내보낼 수 있습니다.
  - PNG·SVG: 문서·보고서에 바로 붙여넣을 이미지용
  - JSON: 다른 컴퓨터로 옮기거나 백업할 때 (**가져오기**로 다시 불러오기)
- Claude 안에서 열었을 때와, 이 GitHub Pages 주소로 열었을 때 모두 내보내기가 동일하게 동작합니다.

## 오프라인으로 쓰기

인터넷 연결 없이도 완전한 단일 HTML 파일이라, 이 저장소의 `index.html`만 있으면 더블클릭해서 브라우저로 바로 열 수 있습니다. 글꼴만 인터넷이 있을 때 더 예쁘게 표시되고, 없으면 시스템 기본 글꼴로 대체됩니다 (기능 차이는 없습니다).

## 알아두면 좋은 점

- 배선은 부품의 특정 핀에 자동으로 "붙는" 개념이 아니라, 자유로운 좌표 기반 선입니다. 포트를 핀 위치에 가져다 놓는 방식으로 표현합니다.
- PCB·박스·범례는 크기가 자유롭지만, 그룹으로 묶은 블럭 자체는 리사이즈할 수 없습니다 (내부 요소 배치는 그대로 유지).
- 여러 컴퓨터에서 같이 쓰려면 이 저장소 주소를 공유하면 되고, 업데이트할 때는 이 저장소의 `index.html`만 새 버전으로 덮어쓰면 모두에게 자동 반영됩니다.
